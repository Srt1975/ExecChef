# ExecChef

ExecChef is a Vite + React app for managing foodservice operations. The current landing page introduces the suite and links to React and Vite from the footer.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Notes

- The app entry point is `src/main.jsx`.
- The main page component lives in `src/execchef.jsx`.
- Shared styling lives in `src/index.css`, and page-specific styling lives in `src/Execchef.css`.
